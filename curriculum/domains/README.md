# domains/

Empty by design. `curriculum/graph.yaml` is the single source of truth for all 35 domains in Phase 1 — see issue #17's "Do not attempt to finish all 35 domains before KUP projects can use the graph." This directory is reserved for finer per-domain detail (e.g. domain-specific reading lists or notes too long to belong in `graph.yaml`) if and when a specific domain needs it; not populated speculatively.
